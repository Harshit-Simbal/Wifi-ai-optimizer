# AI-Augmented Wi-Fi Optimizer

This project predicts and reduces interference in dense Wi-Fi environments using machine learning and real-time scanning (macOS compatible).

## Features
- Real-time Wi-Fi environment scanning
- ML-powered interference prediction
- Optimal channel and power configuration
- Streamlit dashboard for visualization

## How to Deploy on Streamlit Cloud
1. Fork or clone this repo.
2. Go to [https://streamlit.io/cloud](https://streamlit.io/cloud)
3. Select this repo, choose `dashboard/app.py` as the entry file, and deploy.
